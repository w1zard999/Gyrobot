# Контекст сессии 2026-09-28 — схема Tumbller (для продолжения)

Читать вместе с docs/STATUS.md (раздел «Сессия 2026-09-28») и README.md.

## Состояние
- Скетч: `firmware/gyrobot_tumbller/gyrobot_tumbller.ino` — стоит, ездит W/S,
  поворачивает A/D по кругу. Все подобранные значения — дефолты в прошивке.
- Старые прошивки (gyrobot_mov, gyrobot_v5) удалены 2026-09-29, есть в истории git.
- Плата прошита коммитом 835385b (все дефолты в коде = в плате).

## Как работать
- Прошивка: вынуть HC-05, USB → COM10, `flash.bat` в корне.
- После включения: положить на бок, ждать рывка колёс (калибровка ~15–20 с).
- Живые параметры по BT: `python tools/talk.py --port COM13 --boot 0.5 --cmds "kp 20"`
  (wasd.bat при этом закрыт — один порт; talk.py по умолчанию на COM13). BT-порт не ресетит плату.
- Логи езды: `tools/logs/wasd-*.log`, разбор поворотов — `python tools/turnstat.py tools/logs/<лог>`.

## Что можно улучшить дальше
- Лёгкая тряска стоя (±0.6°) — kd/dba подобраны, дальше только механика.
- Хранить параметры в EEPROM (сейчас только дефолты в коде).
