# Гиробот v5 — новая прошивка: двухконтурный балансир

Дата: 2026-09-17. Утверждено пользователем (дизайн + worries по люфту).

## Контекст

Робот v3 (Arduino Nano + MPU6050 + TB6612 + JGA25-370 с энкодерами) стоит, но:
уезжает, наклоняется в одну сторону, после толчка едет вперёд не останавливаясь.

Диагноз (подтверждён живой телеметрией 2026-09-17): в текущей прошивке контур
скорости обезврежен (ksp=0.275 при smax-ограничении ≈0), ktrim=0, ki=0,
zero=−1.40 не выверен. Состояния «позиция» в прошивке нет вообще. Прошивка
новее документации (параметр sfilt отсутствует в STATUS.md), исходник только
на Mac. Решение: переписать прошивку целиком под Windows-инструментарий.

## Архитектура управления — двухконтурный каскад (по образцу B-Robot EVO2)

```
энкодеры → [PI скорости] → tilt_shift (±tiltmax) ┐
           [P позиции]  → v_ref                   ├→ уставка угла = zero + tilt_shift
команда d (водитель) → v_ref, pos_ref             ┘
гироскоп/аксель → [PD угла] → ШИМ ±maxpwm (+dead) → моторы (+дифференциал поворота)
```

### Контур 1 — угол (гироскоп), 200 Гц
- Угол: комплементарный фильтр (alpha, дефолт 0.98), гироскоп ±500°/с
  (65.5 LSB/(°/с)), смещения вычитаются (defaults = живые значения 2026-09-17:
  gbx=319 gby=46 gbz=33, abx=234 aby=−14808 abz=426; оси axu=3 axf=2 axg=1 axt=3).
- Старт: 0.5 с ускоренная сходимость фильтра (вес акселерометра повышен).
- Закон: `pwm = kp*(угол − уставка) + kd* gyro_deg_s` — D напрямую из гироскопа.
  Интеграл по углу (ki) по умолчанию 0: авто-трим нуля делает I контура 2
  (урок STATUS.md о дерущихся интеграторах).
- Выход: ограничение ±maxpwm, компенсация мёртвой зоны: при |pwm|>0 и
  |pwm|<dead → pwm = sign(pwm)*dead.

### Контур 2 — энкодеры, 50 Гц (каждый 4-й цикл)
- Скорость колёс: v = ((ΔtotA*esA)+(ΔtotB*esB))/2, эксп. фильтр sfilt.
- Поправка на вращение корпуса (B-Robot): v_body ≈ v_wheel − kθd*θ̇.
- PI скорости: `tilt_shift = kvi*(v_ref − v) + kii*∫(v_ref − v)dt`,
  выход клампится в ±tiltmax (≈5°), ошибка перед интегралом клампится,
  интеграл клампится (windup-защита).
- Позиция: pos = среднее (totA*esA + totB*esB); `v_ref += −kpos*(pos − pos_ref)`;
  pos_ref двигается ТОЛЬКО командой водителя `d` (урок v4 №1). При включении
  баланса pos_ref := pos. kpos по умолчанию мал (возврат за секунды).
- Поворот: команда turn → дифференциал ШИМ; демпфирование рыскания гироскопом Z
  (ktd). Параметры есть, включаются после базовой настройки.
- Люфт редуктора: зона нечувствительности ~0.5–1.5° на колесе (~1 мм на ободе).
  Переносится фильтром sfilt и I-частью PI; P позиции даёт удержание с точностью
  люфта. Медленное покачивание (если возникнет) лечится sfilt↑ / kvi↓.

### Безопасность
- |угол| > fall → моторы off, сброс интегралов и позиций, arec: авто-возврат
  при возврате в стойку ~0.5 с. autoen: автостарт балансировки после старта.
- Wire.setWireTimeout() — защита от залипания I2C (STATUS.md:132).
- Команда `e 0` в любой момент выключает моторы.

## Протокол Serial (надмножество старого, 115200)
- Телеметрия 20 Гц: `a= r= v= vr= pos= tilt= i= pA= pB= en= fall= hz= imuerr=`
- Команды: `p` · `<имя> <знач>` · `e 0/1` · `s 0/1` · `c` (калибровка гироскопа,
  3 с неподвижно) · `z` (принять текущий угол за zero) · `d <speed> <turn>` ·
  `t a|b <pwm>` (при e 0) · `n [0]` энкодеры · `raw` · `burst` (80 отсчётов
  200 Гц: угол, gyro, v, ШИМ → CSV) · `w/l/f` EEPROM · `h`.
- Параметры: kp kd zero alpha dead maxpwm fall arec autoen · kvi kii tiltmax
  kpos sfilt kth (поправка θ̇) · ktp ktd · esA esB mvA mvB · gbx gby gbz
  abx aby abz axu axf axg axt. Старые имена (ksp/ksi/smax/ktrim) не
  переиспользовать, чтобы не путать семантику.

## EEPROM
Своя структура: magic + version + CRC16 + все параметры. Несовпадение →
загрузка defaults(). `w` — сохранить, `l` — загрузить, `f` — заводские.

## Прошивка и откат (Windows)
- arduino-cli (user-install, без админа) + core arduino:avr; загрузка avrdude
  на COM9 (CH340, драйвер уже установлен).
- ДО первой прошивки: бэкап текущих flash и EEPROM в файлы (avrdude -U r).
  Откат = обратная заливка.

## Заводские испытания (порядок обязателен)
1. Прошить, `e 0`: телеметрия без моторов — r≈0 в покое, угол стабилен,
   энкодеры считают при прокрутке колёс рукой.
2. Знаки: `t a ±120`, `t b ±120` — пользователь подтверждает направление колёс
   («вперёд»), оператор сверяет знак энкодеров; выставить mvA/mvB (вперёд=+)
   и esA/esB (вперёд=+). Не продолжать, пока знаки не сходятся.
3. Баланс без контура 2 (kvi=0): стоит не хуже старой прошивки.
4. Включить контур 2 слабым: толчок вперёд → робот наклоняется назад и
   ОСТАНАВЛИВАЕТСЯ. Если ускоряет — знак kvi неверный, стоп, разбираться.
5. Пошагово поднимать kvi/kii, включить kpos; после каждого шага — толчок.
6. `w` в EEPROM. Критерий успеха: 60 с стойки со смещением < 5 см; толчок
   корпусом — возврат на место; остановка после разгона командой `d`.
