# Одометрия, карта и возврат домой

Дата: 2026-09-30. Статус: дизайн согласован с пользователем.

## Цель

Робот знает, где он и куда смотрит, относительно точки «дом». Клиент рисует
карту пути. По кнопке робот сам возвращается домой по прямой и встаёт в
исходное направление.

## Решения

- Навигация в **прошивке** (не в клиенте): 5-мс цикл рядом с балансом, задержки
  Bluetooth не мешают, при потере связи робот доезжает сам. Управление через
  клавиши из клиента было бы грубым (буквы — только «стоп/полный ход», +100 мс).
- Возврат **по прямой**: разворот к дому → езда → разворот в исходный курс.
  Препятствия не объезжает (датчиков нет).
- Курс — **по гироскопу** (колёса на поворотах проскальзывают), путь — по
  энкодерам.

## Дом

- Автоматически при взводе: поставил робота — это дом (поза = 0, курс = 0).
  После падения одометрия недостоверна, поэтому новый взвод = новый дом.
- Кнопка **R** в клиенте (команда `home` роботу): текущие положение и
  направление становятся домом, след на карте стирается.

## Прошивка

**Одометрия** (раз в 40 мс, только когда взведён):
- путь `ds = (cA + cB)/2` импульсов; 1 имп ≈ 0.40 мм (π·63 мм / 495) —
  константа `MM_PER_CNT`, уточняется замером по рулетке;
- курс `odoTh` — интеграл гироскопа Z (как `heading`, но не сбрасывается
  поворотом и удержанием курса); положение `odoX += ds·cos(odoTh)`,
  `odoY += ds·sin(odoTh)`, в мм;
- телеметрия: `px=` `py=` (см), `ph=` (курс, °, −180…180), `nav=` (фаза).

**Возврат** (команда `h`), конечный автомат раз в 40 мс, выдаёт те же цели,
что клавиши (`moveSet`, `turnSet`), — езда, рампы, поворот на месте по колёсам,
баланс работают как при ручном управлении:
1. `TURN` — поворот на месте к направлению на дом:
   `turnSet = clamp(K_NT·ошибка, ±YMAX)`; переход при |ошибка| < 10°.
   Если до дома < 5 см — сразу к п.3.
2. `DRIVE` — `moveSet → min(MOVE, K_ND·расстояние)` (не ниже малого минимума,
   через ту же рампу), подруливание `turnSet = clamp(K_NT·ошибка, ±40 °/с)`;
   стоп при расстоянии < 5 см (или если дом оказался позади — проскочили).
   Если ошибка курса > 45° (сильно сбились) — назад в `TURN`.
3. `FACE` — поворот на месте к исходному курсу (0°); готово при |ошибка| < 5°.
4. `IDLE` — стоит, удержание позиции как обычно.

Отмена: любая буква W/A/S/D, команда `x`, падение. Параметры навигации
(`K_NT`, `K_ND`, допуски) живые по сериалу, сохраняются `save`.

## Клиент (tools/wasd.py)

- Окно шире: слева текущая панель (клавиши, телеметрия), справа карта.
- Карта: след (точки из телеметрии, ~10 Гц, прореживание), робот стрелкой по
  курсу, дом крестиком, масштаб подстраивается под след (минимум ±50 см),
  сетка 10/50 см.
- Клавиши: **H** — домой (`h`), **R** — дом здесь (`home`) + стереть след,
  **C** — стереть только след; W/A/S/D отменяют возврат (как и прежде шлются).
- При выходе клиент шлёт `x` (стоп возврата).
- Статус: «едет домой: N см» / фаза.

## Проверка

1. Одометрия: проехать ~1 м вперёд по рулетке, сравнить `px`; поправить
   `MM_PER_CNT`. Повернуть на 360° — курс должен вернуться к ~0°.
2. Возврат: несколько поездок с поворотами, H — замер промаха до старта и
   ошибки курса. Подбор `K_NT`, `K_ND`, допусков вживую.
3. Отмена клавишей посреди возврата; падение посреди возврата; R.

## Не входит

Объезд препятствий, возврат по своему следу, езда к произвольной точке мышью.
